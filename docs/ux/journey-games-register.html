Problem

The one recurring manual task in Meridian is logging the day's LinkedIn Games times. Three things get in its way (evaluation of 2026-11-16):

  • From Hoy it takes three taps to start typing, because Hoy reports Games but cannot act on it.
  • A result typed on the wrong game cannot be removed from the dialog: blank rows are skipped, and Guardar is off when all rows are blank.
  • One stray tap outside the sheet, or Escape, throws away everything typed.

Success: the person logs or corrects today from wherever they are in one sitting, never loses typed times, and can undo a mistake.

Interaction

  • Dirty means any row differs from what was stored when the sheet opened. Retyping the stored value makes it clean again.
  • Focus: opens on the first empty time field (first row if all are full); returns to the opener on close. Opening the discard bar moves focus to Seguir editando.
  • Announcements: row errors are role="alert" (as today); the result note and "Se quitará" are role="status".
  • Reversibility: removal is undoable until Guardar through Deshacer. After saving, re-entering the time restores the entry; there is no separate undo.
  • No animation is required. The sheet's existing slide stays and respects reduced motion.

Channels and state

Single channel. The sheet's draft lives only while it is open; it is not persisted across a reload. After a manual sync the page reloads, so avoid starting one with the sheet open (the sheet blocks the sync button anyway).

Success criteria

  • Taps from Hoy to the first typed character: 3 now, 1 target.
  • Sheets closed with unsaved edits: should fall to near zero, and "Descartar" should be rare.
  • Entries removed through the sheet: any use proves the gap was real.
  • Save errors per save, by cause (format vs. network), to see which message is doing the work.

Nothing here is measured today; these need /measure before they mean anything.
