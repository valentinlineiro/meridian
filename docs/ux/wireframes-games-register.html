Hoy · nada registrado

1 The button sits in its own zone below the row’s link, not inside it. A button inside an anchor also follows the link. It is primary because nothing is logged today; once something is, it turns secondary.

Hoy · registrado

1 The result of a save from this screen is spoken by a status region that is in the page before the save happens. The row refreshes in place; the person stays on Hoy.

2 The label changes to “Editar lo de hoy” and the button turns secondary, as on the Games page.

Hoy · cargando

1 Skeletons per row replace today’s dashes, so a slow load no longer looks like missing data. Screen readers hear “Cargando tu resumen” once.

Hoy · una sección no cargó

1 One block for the page, not one per row. Reintentar reloads once, shows “Cargando…” and is disabled while it runs; if it fails again the block says “Sigue sin cargar. Inténtalo en un minuto.” There is no automatic retry.

2 The other rows keep their values; only the failed row says “No disponible”.

Hoja · vacía

1 Focus opens on the first empty time field, so typing starts at once. The native dialog would focus Cerrar.

2 Guardar looks disabled and says why. The sentence is its description.

3 The save row is pinned, so the phone keyboard does not cover it.

Hoja · escribiendo

1 The field masks digits into m:ss as they are typed, so “112” reads 1:12. The field is its own reading; no separate echo line.

2 The average is optional. A time alone is enough to save.

Hoja · quitar un resultado

1 Emptying a stored row does not delete anything yet. The row says what will happen and offers Deshacer until Guardar; saving appends a version of the day without that game.

Hoja · errores al guardar

1 After a failed save focus lands on the first invalid field, and each error is attached to its own input. Nothing typed is cleared.

2 Tango shows an average with no time: today it is dropped without a word.

Hoja · cerrar con cambios

1 Cerrar, Escape, a tap outside and system Back all open this bar when something differs from what was stored. A clean sheet closes at once.

2 Seguir editando is the default focus and the primary button; the loss is named in the sentence above it.

Hoja · sin respuesta al guardar

1 A timeout or a lost connection after the request left may mean the write landed. Saving the same text again returns “sin cambios”, so the retry is safe, and the message says so.

Hoja · pasó la medianoche

1 The title still says 16 nov, but the save would go to the new day. Both buttons name the outcome; there is no Cancelar.

Hoja · no se pudo leer lo guardado

1 Opening empty would suggest nothing is stored. The line says nothing gets erased, and removal is off until the stored values are read.
