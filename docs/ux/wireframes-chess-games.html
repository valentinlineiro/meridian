Partidas, phone

Partidas · 10 recientes

1 "Ver todas y filtrar": the ending, phase, opening and ELO filters exist only after it, and "Ver todas las partidas" names browsing. Activating it moves focus to "Buscar rival", because the button leaves the page [brief-chess-games, Gap].

2 "›" marks a game that opens. The row without it stays plain and, when tapped, shows the status line. Open: what share of games has no stored moves?

Partidas · lista completa con filtros

1 Every control changes the list when the person is done with it: chips, selects and search at once, the ELO fields on blur or Enter. "Filtrar" is gone. "Fin" lists all eight endings [journey-chess-games].

2 The counter is a polite live region, so a screen reader hears what a filter did.

Partidas · derrotas por tiempo

1 The card carries the ending on its own line, so a list filtered by "Tiempo" shows why each row is there.

2 The counter reads "1–7 de 7" after the list loads.

Partidas · ELO mínimo mayor que el máximo

1 Both fields are marked invalid and the message is tied to both. No request is sent; the other filters stay applied and the list is the one before the bounds were typed.

Partidas · sin coincidencias

1 The way out sits in the empty line, where the person is looking. "Limpiar filtros" is also the bar's button, and sends focus to the first chip.

Partidas · fila sin jugadas tocada

1 The status line appears under the heading, above the cards, so it is on screen when the person taps a card. It stays 4 s and clears at the next filter change.

Game viewer, phone

Visor · partida abierta

1 The position line is a live region: stepping announces "Jugada 12 de 78: Cxd4" once. Each move is a button, the current one carries aria-current.

2 Engine losses are in pawns, as in the profile.

3 The board has one text description of the position, in Spanish piece names. The move list is the way through the game.

Visor · fallo temporal

1 A timeout or server error is not a missing game: it says it could not load and offers "Reintentar", which sends one request.

Visor · sin jugadas guardadas

1 The same sentence as the table's status line. A permanent absence has no retry.

Failure states, phone

Ajedrez · la página no cargó

1 One block directly under the hero. The hero shows its title only (no dashes that read as values) and the section index is hidden. The button is disabled while the request runs; a second failure reads "Sigue sin cargar. Inténtalo en un minuto."

Ajedrez · cargando, después de 3 s

1 Skeletons from the first frame, so dashes never stand for values. The line appears after 3 s; at 10 s the request times out and the error block replaces this.

Ajedrez · dos bloques no cargaron

1 Each independent block fails on its own and retries on its own. Card-level blocks are polite; the page-level block is assertive.

2 The last window that loaded stays visible under the message in the app; the chip shows the one asked for.

Forma actual · historial corto

1 With fewer games than the window needs, the card says so and points at a smaller window. It does not draw a blank.
